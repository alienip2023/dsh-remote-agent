## 2. 工程纪律（踩过坑固化的，务必遵守）

1. **`npm run check` 不含 lint**（= packaging + doc-drift + tests）。推送前必须单独 `npm run lint`。
2. **git push 先试常规**（`timeout 25 git push`）；不通走 API 复刻：`node "C:\Users\MR\AppData\Local\Temp\apipush\push-p2.mjs"`（⚠ 传 Windows 路径，Git Bash 的 `/c/...` node 不认）。API 推送后本地 tracking ref 会被沙箱回滚，用 packed-refs 单行重写补（sha 在前 ref 在后）。
3. **只 `git add` 自己的文件**——并行会话可能同仓库工作，`git add -A` 会扫走别人 WIP。
4. **测试跨平台双坑**（Windows 本地假绿、CI 才挂）：
   - 树结构子串断言用 `"name":"xxx"` 精确匹配（Linux symlink 创建成功会让 `link-to-secret` 命中裸 `secret`）
   - macOS `os.tmpdir()` 是符号链接（/var → /private/var），realpath 归一后绝对路径前缀会变——路径断言用 `endsWith` 相对段
   - 文本断言锚**定义处**不锚调用点（`indexOf('applySync(')` 命中 `this.applySync(...)` 调用点，固定长度窗口会随文件增删漂移——本次交接前刚修一例）
5. **每个 doc-drift 的 read() 新目标**要同步 `test/doc-drift-selfcheck.test.js` 的复制清单（lib/node/ 整目录已覆盖，lib/ 根下新文件要单列）。
6. CI 已知抖动：Windows templates.js EPERM 原子写（见上）、偶发 diag:inject runner 失败——rerun 即绿，别当代码问题查。

## 3. 架构速览（关键决策，勿动摇）

- 副机是任务状态权威；hub 崩溃靠 task/sync 对账，reconcile 不重跑 completed。
- 中继只见密文（E2E 默认开，`relayE2E:false` 可关；已知局限：主动降级 + enrollToken 冒充，SECURITY.md 如实钉住）。
- 凭证不离开副机；#27 起副机只自述 provider 键名 + model id。
- roots 是安全边界（realpath 展开 8.3/符号链接后前缀比对）；denyPaths 枚举层生效。
- 产物语义：outputs 是扫描过滤器，不是 final 提升器（final 由内置扩展名表 + artifactRules + dist/ 决定）。
- #25 文件工具走独立 `fs/req`↔`fs/res` 帧，**不进任务队列不占并发槽**。
- 跨版本兼容模式：新字段（queue/runnerKind/defaultModel）缺失时消费方按 null 处理，旧副机/旧 hub 混跑不炸。
